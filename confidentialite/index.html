Politique de confidentialité

Dernière mise à jour : octobre 2026

AvioliStream (aviolistream.shop) propose des abonnements à des profils de plateformes de streaming. Cette page explique quelles données nous utilisons et pourquoi.

Données de nos clients

Pour fournir le service, nous conservons le nom d'utilisateur choisi, le numéro de téléphone, l'adresse e-mail, le profil attribué, le code PIN du profil et la date d'expiration de l'abonnement. Ces données servent uniquement à livrer l'accès, envoyer les rappels d'expiration et gérer les renouvellements. Elles ne sont ni vendues ni partagées avec des tiers, hormis les prestataires techniques nécessaires au service (hébergement, envoi d'e-mails, paiement).

Accès à Gmail

Notre outil d'automatisation se connecte, en lecture seule, aux boîtes Gmail professionnelles d'AvioliStream. Il sert uniquement à retrouver les e-mails de code de connexion envoyés par Netflix ou Prime Video, afin d'afficher le code au client concerné sur la page de connexion.

  • L'accès se limite à la lecture (scope gmail.readonly) ; aucun e-mail n'est envoyé, modifié ni supprimé.
  • Le contenu des e-mails n'est pas conservé : seul le code est affiché au client, et un identifiant technique du message est gardé 24 heures pour éviter qu'un autre client voie ce code.
  • Les données de ces boîtes Gmail ne sont ni partagées ni utilisées à d'autres fins, et ne servent pas à entraîner des modèles d'intelligence artificielle.

L'utilisation des informations reçues de l'API Google respecte la politique relative aux données utilisateur des services API de Google, y compris ses exigences d'utilisation limitée.

Conservation et suppression

Les données d'un abonnement sont supprimées lorsque le profil est libéré après l'expiration. Pour demander la suppression de vos données, écrivez-nous à l'adresse ci-dessous.
